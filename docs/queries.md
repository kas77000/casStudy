# Queries

Generated by `python tools/dump_queries.py --out docs/queries.md`.
Re-run it after changing anything in `casretro/loaders.py`,
`casretro/universe.py` or the session calendar in `casretro/config.py`.

Trade predicate (`config.QATT_TRADE_FILTER`): `not null price, not null size, size > 0`

Symbols are pushed in batches of 500, parent-order ids in batches of 2000.
Nothing is interpolated into a query except table and column *names* --
every value travels as a positional pykx argument.

### [QATT-HT] Market volume profile per CAS session bucket

args: `date`, `list`, `list`, `list`

```q
{[d;syms;bnds;names]
  t:select sym,time,price,size from qatt_17034
    where date=d, sym in syms, not null price, not null size, size > 0;
  t:update bucket:names (`time$bnds) bin time from t;
  0!select n:count i,
           qty:sum size,
           notional:sum price*size,
           pxFirst:first price,
           pxLast:last price,
           tFirst:first time,
           tLast:last time
    by sym,bucket from t where not null bucket }
```

### [QATT-HT] Reference-price VWAP window (17:30-17:45 HKT / 15:00-15:15 IST)

args: `date`, `list`, `int`, `int`

```q
{[d;syms;t1;t2]
  0!select vwap:size wavg price,
           qty:sum size,
           n:count i,
           pxFirst:first price,
           pxLast:last price,
           pxHigh:max price,
           pxLow:min price,
           tFirst:first time,
           tLast:last time
    by sym from qatt_17034
    where date=d, sym in syms, time >= `time$t1, time < `time$t2, not null price, not null size, size > 0 }
```

### [QATT-HT] Last print before the close (17:45 HKT)
